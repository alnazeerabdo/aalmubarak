# أحمد آل مبارك العقارية — Homepage Redesign

A responsive RTL Arabic homepage concept built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and Arabic content.
- `styles.css` — layout, palette, typography and responsive styling.
- `script.js` — mobile navigation, scroll reveals, property filters, testimonials slider and FAQ behavior.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Notes
- Property names, public prices, bedroom/bathroom counts, areas, company contact information and customer-review copy were taken from the public website content available during the redesign.
- Property detail links point to the corresponding current website pages.
- Property and hero imagery is loaded from the original site's public WordPress media URLs, so an internet connection is needed for those images.
- The site uses the Tajawal Google Font in this concept. The live site's exact font setting is controlled by its WordPress Bhume theme customizer and was not exposed in the text-only page extraction; verify the configured font in the site's Typography settings before deployment if pixel-level matching is required.
- The WhatsApp action uses the WhatsApp link published by the site; the displayed phone number is retained separately for telephone calls.
